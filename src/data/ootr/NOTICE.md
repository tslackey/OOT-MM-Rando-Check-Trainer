# Vendored Ocarina of Time Randomizer logic

These JSON files are converted from [OoTRandomizer/OoT-Randomizer](https://github.com/OoTRandomizer/OoT-Randomizer)
(`data/LogicHelpers.json` and vanilla `data/World/*.json`, no MQ). Source revision
`4e7727d565220b2491623cfbd7d0c19d53d3d311`. MIT license: see `LICENSE` in this folder.

Comments and multiline rule strings were normalized into strict JSON for the Vite
bundler. Rule text is otherwise unchanged.

This app is not the official OoTR solver. See `docs/LOGIC_PLAN.md`.
